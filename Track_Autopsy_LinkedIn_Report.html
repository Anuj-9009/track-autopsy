Description

Track Autopsy is a production-grade satirical forensic laboratory and archival document web application that conducts clinical post-mortem examinations on culturally flatlined pop anthems, one-hit wonders, and algorithmic casualties. Users enter any song title and artist into a vintage police blotter docket, triggering a synchronized multi-stage musicological inquest. The application queries Google Gemini 3.6 Flash using a strict structured JSON schema to extract real Billboard Hot 100 historical peak longevity data, original recording studio origins, typewriter transcription of the lethal earworm hook lyric, and a 4-band acoustic spectrum breakdown. Simultaneously, the Spotify Web API is queried via a client credentials flow to fetch high-resolution album artwork and release cataloging. Built with a zero-failure architecture, an internal mathematical generator procedurally produces 100% complete autopsy dossiers offline if API keys are omitted.

Architecture & Design

Modern single-page application architecture built with React 19, TypeScript, and Vite, styled using an authentic mid-century police blotter and coroner docket design system (Space Mono typography, aged manila paper palette #ece8df, distressed borders, and red ink rubber stamps). The data layer features an asynchronous pipeline that concurrently dispatches musicological research queries to Gemini 3.6 Flash and asset requests to the Spotify Search API. The AI engine enforces strict responseSchema typing (Type.OBJECT) to guarantee predictable, type-safe JSON serialization without hallucinations. A client-side localStorage credentials bridge allows users to supply their own API keys via an in-app Config modal, keeping sensitive secrets strictly client-side without committing .env.local to version control.

Technical Challenges Solved

  • Reliable Structured LLM Extraction: Formulated comprehensive JSON schemas and system prompts ensuring Gemini 3.6 Flash consistently outputs verified Billboard metrics, real instruments, and humorous forensic verdicts without JSON parsing failures.
  • Zero-Crash Offline Resiliency: Built a deterministic hash-based procedural generator (utils.ts) that guarantees complete, rich forensic dossiers and frequency spectra even with missing API keys or zero internet connectivity.
  • High-Performance Canvas Waveform Engine: Engineered a 60-FPS dual-phase sine wave oscilloscope on HTML5 Canvas with adjustable temporal sweep speed multipliers and realistic cathode-ray phosphor glow.
  • Full Narrative Cohesion Across 4 Navigation Tabs: Unified the data schema so that the exact studio name, hook lyric, frequency bands, and disposal routing orders persist seamlessly between the Case Registry, Waveform Dissection, Chain of Custody, and Coroner Protocols.
  • Print-Ready Archival CSS Architecture: Built dedicated @media print stylesheets stripping UI chrome and formatting the digital dossier into a sterile, black-and-white physical medical examiner autopsy report.
  • Strict Credential Isolation: Architected local environment management ensuring API secrets remain untracked in git, accompanied by a clean .env.example template for open-source contributors.
